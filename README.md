# Norrgläntan
Detta är hemsidan för Norrgläntan. Här står det vad man kan göra här och visar vägen till hur man bokar för att komma hit.
Detta är bara startsidan, så du kommer ingen vart om du trycker på knappar/länkar.

## Teckniker
Hemsidan är byggt med HTML och CSS.
